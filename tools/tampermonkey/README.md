# 花生 AI 分镜片段下载

安装文件：[huasheng-clips.user.js](./huasheng-clips.user.js)。不需要启动本项目的前端或后端。

需要采集右侧的分镜标注和推荐前三个原视频时，使用[花生推荐素材采集工具](../../docs/huasheng-recommendation-dataset.md)。它将标注、推荐排名和文件信息存入项目 SQLite 主库，支持素材查询和断点恢复，视频文件单独保存。

## 安装与下载

1. 在桌面 Chrome / Edge 安装并启用 Tampermonkey。若扩展提示需要“允许用户脚本”或开发者模式，按扩展提示开启。
2. 在 Tampermonkey 中新建脚本，用 `huasheng-clips.user.js` 的完整内容替换默认模板并保存。
3. 使用已登录花生的浏览器打开或刷新 <https://www.huasheng.cn/video/258950566158483>。
4. 点击右上方的“分镜下载”，点击“读取分镜”。默认选中全部有文件的分镜。
5. 保持“指定文件夹”保存方式，点击“选择文件夹”，选择存放素材的位置，再点击“下载所选”。需要桌面 Chrome / Edge；首次保存时浏览器会请求该目录的写入权限。
6. 脚本自动创建项目文件夹和素材类型子目录，文件以 `001_文稿.mp4`、`002_文稿.mp4` 等顺序命名。下载结束后，`分镜清单.json` 自动保存在同一目录，也可点击“导出清单”再次保存。

例如选择“剪映素材”文件夹后，文件结构如下：

```text
剪映素材/
  工业革命为什么先发生在英国，而不是中国？_258950566158483/
    时间轴片段/
      001_工业革命为什么先发生在英国，而不是中国？.mp4
      002_这个问题….mp4
      分镜清单.json
```

指定文件夹模式通过 Tampermonkey 获取文件内容，再使用浏览器文件系统接口按确定的文件名写入，保存时不采用 CDN 的 UUID 名称。已有同名文件保留，新文件自动加 ` (2)` 等后缀。只有文件写入并关闭成功，列表才会显示“已下载”。

如果旧版保存的文件仍是 UUID，请用完整的 **1.2.0** 脚本更新现有脚本并刷新花生页面，然后选择“指定文件夹”重新下载。脚本不能凭 UUID 猜测已有文件的分镜顺序。

支持停止、重试失败、单独勾选。所有勾选且尚未完成的片段同时发起下载，不设脚本并发上限；重试时所有失败片段也同时发起。每个片段下载完成就独立写入，不等待其他片段。进度变化按动画帧合并刷新，避免高并发时反复重建列表。同一源文件用于多个分镜时，每个分镜分别保留。脚本只读取当前项目，不会点击重新生成或修改项目。

实际同时传输数量和总速度仍受浏览器、网络与素材服务器约束；指定文件夹模式会暂存下载内容，全部并发时内存占用可能增加。文件命名及剪映中的排序不受完成先后影响。

## 素材类型

| 选项 | 下载内容 |
| --- | --- |
| 时间轴片段 | 优先使用编辑器的 `ppt_video` / `composite_video`；没有合成地址时使用当前 `video` 源文件，并在列表标明“源文件（未裁切）”或“图片源文件”。 |
| 原始画面素材 | 当前分镜选中的 `video` 源文件，不包含右侧备选素材。 |
| 分镜配音 | 当前分镜的 `voice` 音频；没有配音地址的分镜标为不可下载。 |

导入剪映时按文件名排序。图片会保存为 PNG/JPG 等图片文件，可以直接导入剪映；脚本不会把图片或 HLS/MPEG-DASH 播放清单伪装成 MP4。

下载的源视频可能比时间轴分镜更长。JSON 的 `playback.timelineDurationSeconds` 是配音决定的时间轴时长；`sourceStartSeconds` 是原素材播放起点；`playbackRate` 和 `loop` 记录播放器的变速及循环规则。`videoClipEffect` / `audioClipEffect` 内的 `trimIn`、`trimOut` 单位为微秒。`metadata.cutting` 是画面空间裁剪参数。

这些文件不是剪映工程，仍需自行导入和编排。合成片段是否已经包含字幕、配音取决于花生提供的实际文件，脚本不会另行混音或烧录字幕。需要独立配音时选择“分镜配音”。

## 常见问题

- **页面没有按钮**：确认脚本已启用、有 `huasheng.cn` 网站访问权限，并刷新编辑器页面。
- **权限不足**：使用能正常播放该项目的登录账号；脚本不绕过项目访问权限。
- **无法选择文件夹**：改用桌面 Chrome / Edge，并确认浏览器已允许网站写入所选文件夹。请通过脚本面板的按钮打开目录选择器。
- **素材网站权限提示**：更新版本新增 `GM_xmlhttpRequest` 权限；按 Tampermonkey 提示允许当前素材 CDN 的读取权限。
- **普通浏览器下载模式**：保留“浏览器下载目录”方式作为兼容选项，但文件夹位置和最终命名仍由浏览器 / 扩展处理。需要稳定顺序文件名时使用“指定文件夹”。
- **下载功能未启用 / 扩展名不在白名单**：仅影响普通浏览器下载模式；可以改用指定文件夹模式，或在 Tampermonkey 设置中启用下载、授权下载权限并加入对应文件扩展名。
- **部分失败或 CDN 地址过期**：先重新“读取分镜”，再下载待下载的文件；原有成功文件保留。
- **页面刚修改完素材或时长**：先等待花生保存和渲染完成，再重新读取。脚本读取当前保存的项目快照，不会主动触发渲染。
- **不可下载**：可能尚未生成素材，或当前仅有流媒体 / 浏览器内临时地址。导出清单会保留对应分镜及原因。

脚本没有外部依赖或上传功能。清单中的 CDN 地址可能含临时签名，作为本地素材记录保存即可。

## 验证

```sh
node --check tools/tampermonkey/huasheng-clips.user.js
node --test tools/tampermonkey/huasheng-clips.test.cjs
node --test tools/tampermonkey/huasheng-clips.browser.test.cjs
```

浏览器测试复用仓库 `frontend/node_modules/playwright` 和本机 Chrome。项目接口和 Tampermonkey 请求使用模拟数据；目录测试使用 Chrome 实际文件系统句柄（站点私有目录）写入并重新读取内容，核对带 UUID 附件名的响应仍保存为 `001_…`、文件字节一致、清单同目录、同名文件保留和取消清理。并发测试在两种保存方式下验证 23 个所选片段在任何一个完成前全部启动、停止取消全部请求，并验证密集进度事件每帧只刷新一次列表。其他测试覆盖排序、批量、重试、停止、登录错误、V2 接口、页面切换和桌面 / 手机布局。原生目录选择弹窗、该私有项目及真实 Tampermonkey 扩展尚未执行完整下载测试。

字段依据：项目页公开的 `app/video/page-a18944b0646dcb05.js`、编辑器 `3800.js`、`7832-d8b7293bd23831f4.js`；Tampermonkey 下载 API 见 <https://www.tampermonkey.net/documentation.php?ext=dhdg&version=5.4&q=GM_download>。花生后续升级可能改变接口或字段。

指定目录接口见 <https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker> 和 <https://developer.mozilla.org/en-US/docs/Web/API/FileSystemFileHandle/createWritable>。
