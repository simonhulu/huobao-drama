# 科普任务删除

在 `/science-pop` 选中任务，使用详情右上角的垃圾桶按钮，确认后从任务列表移除。执行中、花生远端制作中和排队自动导出的任务须先停止。请求失败时保留任务与未保存修改；删除成功后切换到相邻任务，并阻止旧轮询结果把已删除任务重新显示。

## 保留范围

- 删除使用 `job.json` 中的 `deletedAt` 标记，关闭后续自动交付；保留文稿、素材、成片、封面、上传检查点及平台回执。
- 常规列表和任务详情不再返回已删除任务，旧素材接口返回 404。
- 保留 YouTube 视频 ID 去重，频道采集会跳过同一视频；直接再次导入返回明确冲突。
- 批次保留条目并显示“已删除”，跳过后续制作和重试。删除已经完成的任务不会降低历史交付数量或因此追加替代作品。
- 等待同账号空闲的任务被删除后会退出等待，批次正常处理下一条，不将删除记成生产失败。
- 不清理磁盘文件，也不撤回远端作品。

接口：`DELETE /api/v1/science-pop/workflow/jobs/:id`，成功返回 `{ "id": "science-…", "deleted": true }`。重复删除同一任务幂等；无效编号 400，不存在 404，执行中 409，跨站请求 403。
