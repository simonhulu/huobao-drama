# 体育视频主题流程验证

## 行为

- 配置的体育频道按视频人物、事件和主题检索完整新闻，不再排除采访、媒体日、专题、合集、历史回顾、赛前和其他体育项目。
- 比赛日期、双方和比分只作为可选检索信息。没有比赛对象的文章可以翻译、下载关联视频、分离人声、生成配音字幕、剪辑、制作横竖封面并进入现有发表流程。
- 默认中英文同时检索。中文使用原稿，英文只翻译；一篇独立完整原稿一个任务，保留100汉字/100英文词门槛及全文去重。
- 旧内容类型排除记录可以重新采集；已覆盖语言和已建档正文继续防重复。
- 无比赛采访的语音识别采用中性提示；对齐失败自动保留旧结果并重识别一次，成功缓存复用，实际二次失败保留音频和证据。
- 已识别比赛保留球星动作海报；无比赛主题使用原视频高清帧和顶部灰底标题。顶部标题不代表对原画面所有品牌标识进行了清理。
