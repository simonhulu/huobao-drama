# 科普二创：先理解原文，再生成讲述大纲

## 实际发现

旧流程有先分析、再写作的两阶段调用，但分析不足以保住原文的表达欲：好奇心问题序列被当作情绪弧线，证据提取偏向科学结论，场景、比喻和趣闻被大量删去；正式大纲容易变成知识目录。骆驼原稿 6235 字，旧二创只有 717 字，立场从赞叹动物本领转向反复限定说法。

原文明确说“大家都知道驼峰是骆驼储存能量用的”，旧稿却把“驼峰是否装水”当成主要问题。要求每项机制必须填非空限制、强制凑齐三个候选角度，也推动了不必要的纠错叙述。写作同时收到整个原稿时，分析阶段排除的说法还可能重新进入正文。

## 已修改

- 保留两个强制严格工具调用，分析先保存，正文后生成。原文主题、作者立场与表达动机、真实情绪变化、讲述材料与取舍、正式逐段大纲成为必需字段。
- 情绪和材料引用真实原文摘录；大纲必须使用所有选定材料。每段记录场景/动作、解释过程、情绪承接和下一步连接。
- 原文已有明确主题时只需一个重讲入口，科学条件允许为空。必要限定写进可以准确重讲的材料，审稿意见留在分析记录中。
- 写作只接收批准材料、机制、事实和大纲，不再次接收全部原稿或原始引文。避免省略内容绕过大纲回流，以及朗读禁讲理由。
- 旧版本分析不能直接跳过新拆解。原文摘录改写后无法匹配时提供一次明确纠正机会，仍不匹配则停止。长稿篇幅下限只拦截严重摘要化，不作为质量评分，也不要求保留固定比例的原文。
- 页面“二创准备记录”显示主题、立场、情绪、材料取舍及逐段讲法，并明确标记旧记录缺少的拆解。
