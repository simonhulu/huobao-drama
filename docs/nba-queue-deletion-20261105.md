# NBA 队列任务删除

排队任务原先同时受前端批次成员判断和后端全局闲置检查限制，只要同批其他任务正在运行，就无法删除。

现在选择任务后，可通过详情标题右侧的垃圾桶删除尚未开始的制作或上传任务。服务端返回 `canDelete` 和 `deleteBlockedReason`，前端显示实际限制原因。正在制作、上传或发表结果尚待核对的任务保留保护。

执行器逐条读取最新任务，以每个任务的独立租约协调制作、上传和删除。删除后跳过对应任务，保留共享比赛素材，并继续后面的任务。每个任务的租约通过非空目录原子发布，崩溃恢复与延迟释放只能移除自己的所有权文件，避免误删新租约。
