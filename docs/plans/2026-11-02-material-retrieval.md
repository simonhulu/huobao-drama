# 提高历史视频素材命中率

目标：修复已保存说明与原视频的身份关联，提高已有本地视频的有效召回，避免规划错误造成无谓补图。
保护同片素材唯一性、画面核验、当前制作与上传、正文及已完成付费工件，不批量重下视频或复制媒体备份。

1. 修复采集使用合成片 ID 的错误，兼容完整旧检查点；先用合成片分支回归复现，再验证增量采集。
2. 从保存的原始 `metadata.video` 回填对应身份和素材说明；先只读预览，再事务应用，保留推荐与下载记录。
3. 检索按真实素材描述和上下文排序，资产去重、排除已用资产后再截断；仅在有明确记录时放宽未知景别。
4. 临时规划服务错误保留成功批次并重试；拒绝把全片同一个标题查询静默当作完整规划。
5. 使用真实历史镜头重放候选检索，报告命中和候选多样性变化；候选增加不等同于画面已通过实际核验。
6. 在保护活动任务的前提下启用新代码并记录证据；已有成功成片及上传不重复执行。

验证：采集器、素材库、回填、制作检索、规划与唯一性回归，加后端类型检查。实库只读评估与回填结果记录在 outputs。
