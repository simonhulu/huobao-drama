# NBA 直接发表与封面清晰度修复

## 行为

- 开启“制作后直接发表百家号”时，成片使用 CBA 共用账号直接发表，草稿不再算作上传完成。
- 必须选择平台精确 `#NBA#` 话题并读回标签，不能只插入普通文本或选用相近话题。
- 简介为话题预留 50 字预算；原标题和中文稿不变。新发表填写并核验“含AI生成内容”创作声明。
- 历史草稿保留原账号、视频、上传任务与作品 ID，更新封面后在原页面发表。未知提交结果只读核对，不重复上传或发表。
- 保留翻译模式，不恢复事实审核或修稿循环。

## 清晰度原因

本次源素材 `wCjTikWeEBE` 是 1920×1080。旧封面从二次压制的字幕成片截取，缩成 1280×720 JPEG，只有 87,187 字节，上传时又放大到 1600 宽。二次压缩、降采样和放大造成额外细节损失；百家号编辑器也把旧封面标记为“图片模糊”。

新流程直接从源视频的实际剪辑区间取八张原生 PNG，排除异常明暗画面，并比较画面中心区域的清晰度，避免仅依据清晰的比分条选帧。横版保留原生尺寸，竖版按 3:4 裁切且不放大。已有成片只修复封面，无需重新配音或渲染。

本次选帧为源视频第 853.3791835 秒，处于成片素材区间 843.2090236512918 至 894.0598230674038 秒。
