# NBA 独立采集与制作队列

## 修改结果

采集 `collect` 只读取视频主题、检索新闻、去重和入库。采集结束后，自动制作开启的批次将任务交给独立 `produce` 运行，双方通过 `productionRunId` 和 `collectionRunId` 关联。采集成功不再依赖成片或发表状态。

两条队列分别使用 `.collection.lock` 与 `.production.lock`，各自串行，可以同时工作。制作或上传失败、停止制作、制作排队都不会占用采集执行权。共享控制台用短时 `.console.lock` 合并各自运行记录，账号与制作设置在入队可见前原子保存。既有去重、任务删除保护、上传检查点及未知结果核对逻辑保留。

页面显示两条队列及排队批次，可分别停止。原队列也可通过 `/runs/:id/resume` 继续，保留原账号、自动发表选择和任务范围；同一任务已经入队时禁止再次派发。
