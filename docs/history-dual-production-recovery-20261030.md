# 双版独立生产与发表恢复

## 原因与修复

精细化工厂已有两路准备、单路渲染的执行限制，外层双版协调器又以活跃任务数阻止创建 Episode。大量已接纳稿件仅显示外层 pending，没有可见的工厂排队任务。现删除重复准入限制，执行并发保持原值；花生失败、额度不足和结果不明均不阻止精细化入队。

部分旧花生导出仅写兼容交付记录，完成时找不到渠道成片，因而未建立自动发表意图。现核对正文、原文件路径、大小及 SHA-256 后补登记原成片；已接纳双版工作的 completed 导出也会协调补齐遗漏，不重复导出或下载。

补登记时检查同文件旧发表记录，即使其 videoId 为空也复用原任务。有明确提交回执才计为已提交；结果不明不允许创建另一条发表尝试。花生版与精细化版独立登记、独立发表，互不等待。

原有“只补做精细化版”记录在后来明确选择两版生产时，原先仍保留 `motion_backfill`，会继续禁止花生版自动发表。现允许该明确操作将其更新为 `dual`，不重建原任务、不清空完成状态。反向补做操作不会覆盖双版模式。
