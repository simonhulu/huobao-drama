# 第 1113 集镜尾恢复

## 原因

任务 `494f51d1-9a01-4eac-a241-2e0ca7380cc8` 共 314 镜，只有 shot-74 未通过现有 ASR 镜尾校验。

该镜旁白为“他们分别是吴秉鉴的怡和行、潘启官的同文行、卢观恒的广利行和叶”，shot-75 从“上林的义成行”继续。原来的固定长度切分把“叶上林”从姓名中间切开。

缓存 Whisper 把相关专名识别为“五柄舰的移合型”“攀起关的童文型”“卢关恒的广丽型”。该镜错字集中，文字匹配置信度不足；同音和分句末尾恢复条件也无法满足。反复使用同一识别缓存不会改变这个结果。

## 修复

增加少量不可靠切点的合并策略，保留原正文和配音，不生成按字数分配的时间码。用相邻后镜已经通过校验的实测镜尾作为合并后的切点，并记录原镜头 ID 与设计。

修复只适用于零星缺口；全段识别失败、连续缺口过多、合并超过三个镜头或实测跨度超过 20 秒仍会拒绝，避免把整片退化成长静态画面。

本集合并 shot-74、75，实测范围 339.760 至 352.820 秒，合计 13.060 秒。保留 shot-74 的 ID 和视觉设计，原 shot-75 的记录保存在 `audioBoundaryRepairs` 中。正文顺序、文字和母带均不变。

实际恢复结果：313 镜、312 个实测切点、409 条完整字幕、44223 帧，总时长 1474.1 秒。已核验全文逐字覆盖和各切镜不早于对应实测镜尾。
