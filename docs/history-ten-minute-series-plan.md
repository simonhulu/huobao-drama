# 历史长源浓缩成约十分钟：分集和包装方案

状态：方案，尚未实现。响应用户 2026-10-28 提出的“十分钟上下、情绪弧线全部保留，必要时分上下集，并在标题、封面和开头让观众看懂集数”。既有正文、任务与成片不在本方案阶段改写。

## 默认决策

默认一集，目标 9–11 分钟。能够完整保留情绪转折和关键因果就浓缩为一集；确实有两个相对完整的故事问题，或单集会损害必要转折时，再拆上下集。三集及更多必须由实际故事阶段支持，不按原视频时长机械等分。

“全部保留情绪弧线”应落实为：原文每个有效情绪节点都有去向，其触发事件、认知变化和后果在新稿或整个系列中有对应。可合并连续同义的铺垫，但不能删掉失败只剩成功、删掉希望只剩悲剧，或为了缩短时长移除转折的原因。保留来源阶段 ID 与对应集/段落；若不可兼得，选择合理分集，不以加快配音、裁掉句尾解决。

在新角度下重新讲同一组事实，不能照原文逐句缩写。整体情绪弧线跨系列完整，每集又有自己的开场问题、推进、转折和阶段回答。切分优先落在阶段结果、局势转折或问题转换处，不切在人物行动一半。

现有默认音色的一份实测母带约为 3109 个旁白字 / 778.6 秒，即约 240 字/分钟。先以每集约 2300–2500 字安排预算，前情与结尾也计入。实际时长以本次配音为准；复用成功母带，不为了命中 600 秒反复改稿重配。

## 标题、封面、开头、结尾用同一个分集信息

| 位置 | 两集默认做法 | 作用 |
| --- | --- | --- |
| 发布标题 | `共同主题（上）：本集问题` / `共同主题（下）：本集问题` | 从单条标题就能识别主题、次序和本集价值 |
| 封面 | 固定系列视觉；明显的 `上集 · 1/2` / `下集 · 2/2`；主标题突出本集冲突 | 缩略图可辨集数，两集封面不只是换一个数字 |
| 第一集开头 | 先给主问题和冲突，再用一句话点明“这一集先讲什么” | 不用长目录或片头消耗十分钟预算 |
| 第二集开头 | 一两句交代上集改变局势的结果，立刻提出本集新问题；约 10–20 秒 | 没看上集也能听懂，看过的人不必重复听长回顾 |
| 非末集结尾 | 回收本集问题，用已建立的因果提出下集问题 | 有阶段满足感，不靠突然截断制造悬念 |
| 最后一集结尾 | 回答系列最初问题，明确收束 | 不自动附加没有计划兑现的“下集揭晓” |

三集以上统一为“第 1 集 / 共 3 集”等明确编号；只有先锁定总集数才能写上下集或第 N 集。单集不加多余的“第 1 集”。

发布标题继续从**来源原标题**改写，保留与本集有关的主要人物、年代、数字和主题词，去掉推广词。集数是必要结构信息，不能当成推广标签删除。来源里原有的集数与新浓缩系列集数分开，不能照抄原片“第 20 集”。

以“秦朝亡了没人救，汉朝亡了凭什么还能再活两百年？”为包装示例，待正文划分确认后可采用：

- `秦亡汉续两百年（上）：秦朝为何迅速崩溃`
- `秦亡汉续两百年（下）：汉朝靠什么恢复江山`

封面可用共同小标“秦亡汉续两百年”，主文分别突出本集问题，并清晰标注“上集 · 1/2”和“下集 · 2/2”。这只是结构示例，不代表已完成对应新稿或史实审阅；不得为了套示例强改本集立场。

不要只在简介写“上集”、把集数埋在难读角落，或两集使用完全相同的标题。没有发表的下一集，只能预告内容，不能声称“下集已更新”。本阶段不依赖平台合集、置顶评论或自动补链接；同系列名、集数和封面已经足以让观众识别。

## 在现有流程里怎么落地

1. 使用 gpt-6.1-sol 分析完整原文，输出核心观点、故事结构、带具体触发事件的情绪弧线及三种角度。长源超出单次上下文时按原事件段落分批读，汇总节点后再定整体结构，不能只读开头。
2. 在选定角度后确定“单集浓缩 / 上下集 / 必要的更多集”，一次冻结每集核心问题、覆盖情绪节点、阶段结局、目标时长和总集数。默认自动决定，不加逐集审批。
3. 按计划生成各集正文和必要前情、结尾。一次核对情绪节点覆盖、因果完整、分集边界及预计时长；出现具体缺失时只修对应段落，不做无限审美改写。
4. 从同一个系列记录给标题、封面、开头传入系列名、集序、总集数、本集问题、前情和下集问题。开头、前情和结尾在**二创阶段**写进正文；进入花生/Remotion 后冻结正文，制作阶段不再额外插旁白。
5. 每集作为独立已保存稿件进入现有两版制作，每集各有花生版和精细化版；共用同一集数、正文和发布包装。制作版本和内容集数是两个概念，不能把花生版叫“上集”、精细化版叫“下集”。
6. 页面只增加一个系列分组与“上集 / 下集”切换，继续使用现有正文、制作、成片与发表页。无需新增系列创作平台。

建议把新增系列按集序启动，避免下集早于上集进入制作。若以后允许各集并行，还需单独明确同版系列的发表顺序；这与已确认的“同一集两种制作版本谁先完成谁先发表”不同，不能暗中改成等待所有集齐。

## 最少但有效的验收

- 情绪节点清单能逐项对应到新稿；合并节点保留触发事实，不只保留“紧张/悲伤”等标签。
- 每集时长约 9–11 分钟，以实际配音时长复核；旁白完整，切镜不截断语音。
- 标题、封面与开头的集序、总集数和本集承诺一致；前情内容与上一集实际结尾一致。
- 两集有独立阶段回答，又共同完成总体问题；末集不留虚假续集预告。
- 两个制作版本分别交付和发表，集数与版本不混淆；已有单集任务兼容。
- 程序可检查字段一致、字数、时长与覆盖映射；故事吸引力及“前情是否够用”仍需实际观看判断。
