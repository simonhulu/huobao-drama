# 历史视频标题的联网参考研究

研究日期：2026-10-21。范围：历史脚本发布包装的公共机制，不修改任何脚本、数据库或已保存标题。

## 结论

从正文提取关键词，再搜同题标题，比仅要求模型“更有悬念”提供了更具体的可比较样本。应学习样本的提问方式、主体前置、反差和承诺，而不是把它的数字、因果、细节和整句文案搬进自己的标题。

本文收录的是实际搜索返回的标题，不是已证明高点击率的“爆款”。没有取得曝光、点击、阅读、完播或互动指标，不能据此推断点击率。搜索标题也不构成历史事实证据。

针对 #52，正文是从三国归晋到隋朝的概览。它支持突出“刚统一的司马家发生内斗”“五胡十六国与南北朝的关系”“南北政权如何换到隋朝”等题眼；它不是贾南风权谋或八王详细战事专题。以下宫斗类参考仅能借其表达结构，不能承诺本稿没有展开的细节。

## 获取方式与证据边界

按 agent-reach 的搜索、网页阅读路由获取。已知环境没有 Exa MCP 服务，使用现有 MiniMax `web_search` 作为搜索后端；网页阅读使用 Jina Reader。没有登录、绕过验证码或抓取受限账户。

搜索服务并不可靠地执行 `site:` 约束。例如 `site:baijiahao.baidu.com 八王之乱 西晋 为什么` 返回大量头条、百科和趣历史结果。因此平台必须按返回 URL 的实际主机名判定，不能按查询词或摘要写着“百家号”就认定平台。

检索得到百度百家号旧域 `baijia.baidu.com` 的同题结果，见 R06。本文保留搜索实际返回的 URL，不把它改写成尚未验证的 `baijiahao.baidu.com` URL。当前证据只能确认搜索服务将该结果标为“百度百家号”，没有成功读取原页面来再次核实平台和完整内容。

两条原页面阅读尝试均失败：

- R04：`curl -L --max-time 20 -sS 'https://r.jina.ai/https://www.toutiao.com/article/7496760898489434659/'`，连接 20 秒超时，exit 28。
- R06：`curl -L --max-time 20 -sS 'https://r.jina.ai/https://baijia.baidu.com/s?id=1647086599135641003&wfr=pc'`，连接 20 秒超时，exit 28。

因此下列全部样本均标为“搜索标题/摘要”，不能声称已读全文。原页面失败没有被静默提升为全文证据。

## 四类可借鉴结构

以下适配建议用于创作与人工判断，不是自动生成的质量审核门槛，也不会据此触发否决或重新生成。

### 1. 已知成就与反常结局对撞

R01 把“结束三国、完成统一”放在“为何短命”之前；读者先识别对象，再感到结果违反预期。可借的是“明明做到 A，却出现 B”的逻辑，不是“注定”这种未经正文证明的宿命论。

适配检查：标题本身是否让人知道谁、做成什么、发生什么反常结果。仅有“刚统一天下又乱了”，主体与具体动作仍被藏到副标题，不足以完成这件事。

### 2. 把抽象名词改成可想象的行动

R03 将“皇族争权”口语化为“司马家互殴”。可借的是把主体与动作前置，让观众迅速形成画面；不是照搬“16年”或虚构互斗台词。R04 的“狗血宫斗”则会引导读者期待人物阴谋细节，与概览正文的承诺不一致。

适配检查：保留正文能兑现的动作与后果，拒绝把标题的力量建立在正文没有讲述的宫廷案件、野史和动机上。

### 3. 常识误解与具体代价反转

L01、L03 用“不是懒，而是熬不起/穷”将价值判断转成经济问题。可借的是“读者原本怎么理解，稿件给出了什么具体解释”。若正文只谈照明成本，不能为了刺激改成 L02 的“保命”，因为后者还承诺危险或惩罚证据。

适配检查：反转后的关键词必须是正文中的真实解释，不靠“真相扎心”“90%的人不知道”等空泛包装代替信息。

### 4. 混淆消除与明确的知识收益

R05、R06、R07 都不回避题材关键词，而是把复杂历史的阅读困难变成点击理由：时间线、并行关系、王朝接力。与 #52 的概览性质相容，但“完整”“一口气全部讲清”仍需按实际覆盖范围收敛。

适配检查：标题提出的辨析或串联关系，正文必须真的展示；不能把只有一段提及的知识点包装成深入专讲，也不能为泛泛目录标题自动判定“好奇心强”。

## 公共机制应保存的最小研究链

1. 从当前正文提取人物、事件、对象和可以兑现的反差，构造多个短查询；不能只用泛词“历史 标题”。
2. 优先检索用户要求的平台，按实际 URL 主机过滤和去重；无该平台命中就如实记录，不能拿百科或其他平台凑数。
3. 将样本的原始标题、URL、查询词、获取日期、搜索摘要与原页可读状态一并保留。无指标时仅称“同题参考”。
4. 通常选出 3–5 条真实原题，只有 1–2 条相关参考时按实际数量使用，分别调用 LM Studio 的 `qwen3.5-9b-writing-dpo@q4_k_s` 并关闭思考，系统指令原样使用用户指定的自然化、情绪冲突、好奇与求知欲改写要求。保存原题与改写的一一对应记录。零条或全部不相关时由项目文本模型基于正文原创一个标题，保存检索快照与兜底原因，不伪造网络来源。
5. 网络样本提供表达参考，当前稿提供事实与内容承诺，二者不能互换。搜索摘要只存档，不交给选优或配套写作，避免材料混淆；创作时尽量避免本稿无据的数字、内幕和错误因果，不另设自动质量审核。
6. 锁定改写结果后配套，保留统一标题、25 字、符号白名单、200 字简介、真实来源编号及正文连续原句的完整性校验。多候选只调用 `history-title-select` 比较好奇心与求知欲，单候选直接采用；不调用 `history-title-review`，不要求逐项通过、`title_hook` 或 `title_emotion`，不因质量意见拒绝或重生成。真实参考、格式合格和模型选中是不同证据，均不等于点击率已经提升，也不是未执行审核的通过证明。

新自动方案保存 `selection_mode: 'curiosity'`、`reviews: []`，当前 `coverPlanStatus` 为 `selected`；旧的真实通过审核记录仍为 `approved`，过期与缺失状态不变。页面对新自动方案显示「选中」「备选」，不标「淘汰」或「缺少审核」。可选手工审核入口保留，既有审核记录不改写；生成期间正文或已保存方案变化仍拒绝覆盖。

## 不可借用的内容

- #52 未详细讲述的贾南风谋划、逐王结盟和战场过程，不应被参考标题诱导成主要承诺。
- 不能借用“全员被杀”“仅八人参战”等不准确绝对化说法。
- 不借用未在当前正文展开并核实的 16 年、三百年、人口损失、军队规模和灯油价格，也不以这些数字拼造“震惊”标题。
- 不把西晋灭亡或数百年分裂归结为一个人、一场宫斗或单一制度，除非当前稿确实论证了这种因果且证据可靠。
- 不把检索位置靠前、标题口吻激烈或标题自称“爆款”，当作它有优秀点击率的证据。
