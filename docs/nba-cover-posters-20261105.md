# NBA 双球星对阵封面

封面改用双方出场球员的真实半身或全身动作照、中文队名、终场比分、比赛当地日期和当前新闻标题。横版 1920×1080 与竖版 1080×1440 独立排版，当前样式为 `nba-action-poster-v2`。中文文字直接渲染，长标题完整保留并自动适配。

选人来自同场 ESPN boxscore，排除 DNP 和零分钟。`nba-cover-subject.ts` 根据中英文原标题、中文封面标题、正文和实际出场名单选择报道主角，具体事件优先于最高得分；只接受对应球队名单内的球员 ID。模型只负责选图人物，不改写稿件、不做事实审核。完整输入指纹缓存选择，45秒超时或失败时保留原来的英文标题匹配、得分排序回退。每队最多尝试三名实际出场球员。

TheSportsDB 精确姓名检索和详情接口提供透明原图，保存来源、原生尺寸和 SHA256。生产与上传会传入近期12个已发起上传任务的封面照片摘要，排除当前任务；同一球员的合格候选中优先选近期未用过的照片。没有其他合格照片时保留第一张可用图，所以这是减少重复而非保证每次都有新照片。`selectionReason` 和 `recentlyUsedPhoto` 保存在封面证据中。视觉检查实际球衣球队及完整身体构图，不能把当前球员资料当作旧照片属于当前球队的证据。纯头像和旧球队球衣被排除；没有合格身体图时使用队名，不回退大头像。

动作照保留头顶、肩臂、球衣、篮球和真实姿态。按用户最新要求，以整体观感为准，默认直接使用真实原图，保留球衣、篮球上的自然品牌，不逐个消除小标。局部修补工具保留为显式可选能力，不进入默认自动流程。裁切先生成图片缓冲，再执行透明边缘 trim，避免 Sharp 操作顺序导致合法图片被误降级。平台最终审核仍由平台决定。

真实动作版样例保存在 `outputs/nba-cover-posters-20261105/nba-b58390cfe063609a0a5b/sample.json` 指向的横竖 PNG，原始素材和检查证据同时保存在该目录及 `outputs/nba-cover-action-20261105/sources/`。湖人使用东契奇运球照，热火使用同场实际出场的阿德巴约持球照；字母哥的雄鹿旧球衣图被排除。原图分别为 500×500 和 700×700，海报画布并不表示照片具有 1080p 原生细节。早先 `poster-v1` 文件仅保留作头像版对照。样例脚本只读已有任务，不改旧作品或重新上传。

默认封面制作不依赖 OpenCV。可选本地修补使用已有 Python、OpenCV 和 NumPy，可通过 `NBA_COVER_PYTHON` 指定环境。动作照检查使用 `gpt-6.1-terra` 视觉模型，仅检查图片，不对已发表英文新闻增加事实审核。
