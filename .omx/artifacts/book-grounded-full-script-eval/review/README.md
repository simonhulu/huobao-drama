请不要查看同级目录之外的实验文件，也不要根据文件长度猜测版本来源。

每组按同一顺序评阅：

1. 完整读完甲稿，独立判断它能否不经修改直接发布。
2. 完整读完乙稿，作同样判断。
3. 再选择甲胜、乙胜、平局或两篇都不能发布。
4. 只记录最影响判断的一项原因；如发现事实、观点、仿写或结构硬伤，请注明原句。
