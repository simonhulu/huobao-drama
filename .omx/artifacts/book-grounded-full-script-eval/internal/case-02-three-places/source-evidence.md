## 1. Overloaded Opening Paragraph

- `southern-weekend-commentary-writing` — `第三讲　怎样练成别人杠不赢的强逻辑 / 第四节　如何在评论中更好地体现逻辑感 / 一、逻辑推理三板斧：痛点切入—问题导向—链式延展`
  - Craft move: start from the listener's pressure point before delivering the full chain.
  - Excerpt: "先从一个大家关心的痛点切入，然后以问题为导向梳理逻辑，再用层层递进的方式进行论证和延展。"
- `miaozan-copywriting` — `第12章　你没有看错，做文案要好好Kiss / 预写`
  - Craft move: keep only material tied to the current opening job; defer extra outline pieces.
  - Excerpt: "先写框架，然后以清单形式整理要点或数据，认真看看每一点是否与主题紧扣。"
- `copywriting-fundamentals` — `047 有关系、有好处、有意思、有期待`
  - Craft move: establish immediate relation to the listener before explaining categories.
  - Excerpt: "有关系，是说同受众有关系，是建立相关性。"

## 2. Predictable Corrective Syntax

- `copywriting-fundamentals` — `060 这四种沮丧，请您查收`
  - Craft move: reject overly smooth, expected formulation even when each sentence seems locally correct.
  - Excerpt: "每句话都顺流而下，每个环节看起来都非常连贯，但实际上只做了最肤浅的推导。"
- `copywriting-fundamentals` — `066 从一到万，从万到一`
  - Craft move: generate alternatives before accepting the first available hinge pattern.
  - Excerpt: "通常大家最先想到的几个都很有可能是一样的。"
- `miaozan-copywriting` — `第1章　想要别人看你的视频，先看这24招 / 比较式问句`
  - Craft move: vary the logical form of distinction instead of leaning on one repeated negative-positive frame.
  - Excerpt: "用'我'比较'你'或是'你'比较'我'变换句式，也是轻松写标题的办法。"

## 4. Competing Metaphor Load

- `southern-weekend-commentary-writing` — `第三讲　怎样练成别人杠不赢的强逻辑 / 第五节　评论写作应注意的逻辑误区 / 三、以喻代证与概念偷换`

  - Excerpt: "不能光有比喻，而没有论证，应该在用了比喻后进行必要的论证。"

  - Excerpt: "一个新鲜的比喻、一个刚刚发现的新的修辞方式，那都不太算是洞察。"
- `copywriting-fundamentals` — `087 “禁止吸烟”是好文案吗？`
