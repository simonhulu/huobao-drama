# Offline Writing Corpus

This directory stores the four approved writing books as Markdown with source fingerprints,
chapter or page locators, and parse/OCR coverage. It is offline evidence for isolated editing
experiments. Production skills must not load the full corpus or treat source coverage as proof that
book-grounded editing improves finished scripts.

Use `tools/writing-corpus/search-book-source.mjs` only after a complete manuscript has exposed a
specific writing problem. Original excerpts may inform the isolated editor, but candidate scripts
must pass source-overlap review before human evaluation.
