# Asset validation failure

Only use this note for `ASSET_INVALID` or `ASSET_CONTACT_SHEET_FAILED`.

- Verify that every panel resolves to an existing file and that no two files share the same content hash.
- Judge visible subject count, relationship, action, emotion, required evidence, continuity, sharpness, and absence of generated text.
- A visually attractive image still fails when its semantic evidence must be inferred from narration.
- Reject and regenerate only the specific failed panel; then rebuild the contact sheet.
