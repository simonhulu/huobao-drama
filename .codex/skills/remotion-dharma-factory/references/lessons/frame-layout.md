# Props or frame-layout failure

Only use this note for `PROPS_BUILD_FAILED` or `FRAME_RENDER_FAILED`.

- Fix stale TTS, asset approval, props fingerprints, or layout inputs at their source.
- Use the frame sheet to check full-screen five-panel layout, gutters, bubbles, subtitles, quotes, page reset, and overlaps.
- Do not render a preview video to discover layout errors.
- Keep narration windows sourced from TTS titles and keep the fixed 1280x720, 30fps profile.
