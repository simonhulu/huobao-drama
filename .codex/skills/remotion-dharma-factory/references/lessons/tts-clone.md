# TTS failure

Only use this note for `TTS_TASK_FAILED` or `TTS_CLONE_INVALID`.

- Narration is generated by the MiniMax provider (remote API); there is no local model, clone reference, or warm-up probe.
- `TTS_CLONE_INVALID` now means the active audio provider or the fixed narration voice changed after environment validation; restore the fixed MiniMax voice and re-run environment validation.
- Do not launch a duplicate `tts.pre_generate` while the existing task is queued or running.
- A regular failure usually indicates a MiniMax API error or timeout; repair credentials/quota and resume the same task.
- The runner allows one machine retry, then at most two explicit `retry-stage` repairs. Do not raise the retry budget or edit task attempts by hand.
