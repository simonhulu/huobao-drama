# Image task failure

Only use this note for an image submission, task, or retry error code.

- Recover an existing task from its deterministic frame type before submitting anything new.
- Submit dependency-ready panels as one wave; do not serialize creative planning with generation.
- Retry only the failed panel within its fixed attempt budget (first submission plus three retries). Never regenerate the whole batch.
- If the panel attempt budget is exhausted, revise that panel's creative input in a new manifest/state.
- Preserve task IDs, generation IDs, attempt numbers, and submission intent in the run state.
