# 素材与编辑合同

协议以 `backend/src/services/history-motion-production.ts` 的 Zod schema 为准。自动流程的导演模型输出固定 `shotId` 的目的、查询、画面类型、必要地图/图表/标题与声音建议；它不重写旁白，也不扫描素材数据库。

## 受限检索

```json
{"query":"红军 瑞金 行进","shotSize":"wide","limit":20}
```

可选 `projectId`、`clipId`、`durationMax`。`shotSize` 为 `wide|medium|close|any`，来自语义标注，不从宽高比推断。`durationMax` 限制源片时长，不是镜头需求时长；能裁切的长素材不要被机械排除。

后端只返回有限候选，含 `assetId/rank/description/shotText/query/duration/width/height/fps/projectId/clipId/shotSize/sha256`，并在受控素材根目录校验真实路径。原 `description` 是素材标注，`shotText` 是原分镜上下文，二者都不等于本轮已观察画面。完整数据库、SQL、Cookie 不进入模型上下文。

## 成片级素材唯一性

同一成片内每个视频和图片文件只能使用一次。提交选择前以素材 ID 去重，再对实际读取到的文件计算 SHA-256；相同文件换裁切、改入点、翻转、改色或改名仍算重复，不能用这些变化凑镜头数量。生成图、已有图和本地视频都参加同一成片级哈希集合；重试时复用已经成功的工件，但不得把它再次分配给另一个镜头。地图按底图哈希加城市、路线、区域和包围动作识别是否为重复镜头；同一地形底图上的不同地图内容可并存，单改标题、时长、颜色或运镜不算新内容。

当前高效默认按检索排序检查前三候选：新素材最多两帧自动观察并缓存，明确内容/时代冲突才顺延；观察不足或超时标未核验。没有人工置信度审批。手动局部改选也只能选该镜合法候选，仍验证时间和路径。

```json
{
  "assetId":"真实候选ID",
  "inPoint":0,
  "outPoint":5.5,
  "crop":"cover",
  "reason":"符合本镜人物、时代与行动表达",
  "shortfallPolicy":"reject"
}
```

入出点单位秒，范围不能超过实际媒体。自动流程在片段短于旁白时写 `shortfallPolicy:"freeze"`，用最后可用帧覆盖尾段；它是明确降级，不能记录为连续实拍。`confidence` 字段仅兼容旧协议，不是默认阻塞条件。

## 决策与观察分开

任务的 `decisions.json` 保留目的、查询、有限候选、选择及入出点、画面类型、动画、声音、地图来源和 fallback 原因。实际看过的画面证据另写在本次回看记录，至少包含镜头/输出时间段、源片时间段、检查方式和发现。不要把检索描述复制进 `visualEvidence` 后声称看过。

| 视频检查 | 高效处理 |
| --- | --- |
| 原字幕/台标 | 代表镜头查看实际选取段，避免与新字幕重叠；必要时换片段/取景，不伪称自动去字幕 |
| 原声音 | 自动 composition 默认静音源片；若保留有叙事价值原声，明确记录混音决定，不能与旁白冲突 |
| 镜内切换 | 用源片起点、中段、末尾及连续播放确认具体问题；切到不相干内容时缩短范围或换候选 |
| 人物运动 | 优先保持原运动与稳态取景；跟头/道具特效需动态坐标证据，否则用屏幕文字或留白 |
| 短素材 | 记录实际取用段和尾帧停留；长停留影响表达才局部补图或换镜 |

`probeMotionVideo()` 验证可读性、时长和尺寸；`history-motion-visual-evidence.ts` 最多两帧模型抽检，记录所见、时代线索、字幕、样本差异和本镜适配，缓存观察供后续复用。它不能保证识别所有硬错，不能代替精确 OCR、连续切镜检测或人物跟踪。没有做的检查写未知；普通未知不增加人工审批，已发现严重错配则修复相关镜头。

自动视觉观察每个任务默认有 90 秒总处理预算（`HISTORY_MOTION_REVIEW_BUDGET_MS`），每个新素材最多两帧；这是计算时间预算，不是已观看 90 秒视频。耗尽后标记剩余素材未核验并继续，实际结论仅限记录中的采样画面，不证明人物身份、历史事件、地点、年代、素材连续性或地图结论。报告写明观察方式、范围和未检查项；历史真实性仍需独立史料审阅，成片好看仍需实际观看与听审。

人物连续性优先复用原 Episode 合格画面或同人物参考。自动图片服务目前以提示词、缓存和复用约束连续性；身份、服饰和道具是否连续仍需实际画面证据。生成图片、影视画面和现代地形的类型与来源分别记录为情景示意、素材说明、现代地理参照，不冒充史料原件；这些制作元数据不默认烧录成常驻角标。`sourceNote` 可保留在编辑记录中，成片不自动显示。
