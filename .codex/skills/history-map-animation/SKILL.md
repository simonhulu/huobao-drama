# 历史地图动画

交付可播放地图片段及其数据来源、动画计划和检查记录。地图选择的核心规则：当本镜重点是下列任一内容，且地图能清楚表达时使用，不要求同时出现行军或部署变化。

- 空间关系或部署变化：地点、地形和军队之间的关系如何影响局势。
- 战役成败：用旁白明确的溃退、守住、失守、收复等动作或结果讲清胜负。
- 势力范围的消长：哪些据点或区域扩张、收缩、易手。
- 行军路线：从哪里出发、经过哪里、到哪里抵达或撤回。
- 各方势力的兴盛、衰落与消亡：用旁白明确的关键据点、控制变化或阶段结果讲清局势演变。

每镜写清表达目的与可见动作或结果；只提到地名或胜负、兴衰词语不足以决定使用地图。人物情绪或对话优先素材或图片。战败不自动等于失城，失城不自动等于势力灭亡，兴盛不自动等于疆域扩大；控制变化必须有正文依据。不能把一张地形贴图加一个城市点当成地图推演完成；成片必须让观众看懂本镜的空间关系、动作或结果。

效率优先：复用已有地图范围、矢量和地形缓存；先把本镜一个关键动作做清楚，再决定是否需要更多图层。默认不做全片精确古界复原，不为每镜重新下载底图，不以增加粒子、光效或标签数量代替表达。

## 先确定地图要表达什么

从已锁定旁白提取时间、地点、势力和事件，建立按旁白时间排列的状态。区分国家疆域、地方控制、临时进攻态势与军队位置；战败或被围不等于国家灭亡。保留历史不确定性，不把示意区域换算成精确面积或占比。

每个地点记录经纬度、现代坐标来源、古今名称对应依据；每次控制变化记录时间与史料依据。已知起终点但无古道证据时，路线可以示意，必须标注。不要让模型凭叙事生成貌似精确的古代国界。

按本镜核心选择表达任务：位置关系、沿线移动、攻守或战役结果、控制范围消长、包围压缩，或以关键据点与阶段结果表达势力兴衰消亡。位置关系可用区域建立、聚焦和地点强调；攻守、胜负、消长或兴衰旁白必须有对应的动作或状态结果，不能降成静态单点地图后仍称为推演。缺精确战线时可画明确标为“部署示意”的概念态势；只表达正文已有的相对关系，不附会精确边界、距离或军队坐标。短镜头节奏见 [镜头设计](references/shot-design.md)。

工厂将 `title`、`places`、可选 `routes`、`presentation` 和 `forces` 交给地图准备器；`presentation.kind` 为 `locate`、`route` 或 `encirclement`，不从模型接收坐标、边界顶点、兵位或头像文件路径。可执行的包围及城市驻军示例见 [镜头设计](references/shot-design.md#可执行字段示例)。

## 中文历史地图的原生渲染

用户已明确选定 `jiangshan-map` 的地形、中文标注和地图观感作为中文历史地图升级方向。需要这种画面时，直接复用其原生地图渲染、标签布局与图层样式，在同一投影上叠加现有逐帧军事动作和旁白同步。不要只导出 GeoJSON 再简化重画，也不要把静态截图推拉称为原生地图引擎适配。

已有独立原型通过帧号驱动江山原生相机，用 `MercatorProjector` 与 SVG `getScreenCTM()` 获取每帧位置，叠加军队、旗帜、路线与占领判定。基础版为固定12秒演示；新增 `--variant refined` 的18秒精细版，使用两位将领示意头像、骑兵/步兵透明素材、曲线箭头和合围动作。四种素材按生成记录与哈希缓存复用；头像不是考证肖像，兵形不表示实际人数。实现、命令、固定上游版本和数据限制见 [江山原生地图适配](references/jiangshan-native.md)。两版均限1080p横屏固定演示，精细版最终质量以对应成片QA为准；通用事件计划、任意稿件和竖屏接入尚未完成，既有自动生产仍使用下面的地形准备流程，不能声称已全部迁移。

精细版连续片先采集整段每帧的原生坐标与文字框，调用 `prepareJiangshanRefinedLayout()`，再把同一 `layout` 传入每帧渲染。以全镜头固定偏移及连续边界夹紧安放兵形和头像，保留地理锚点和引线；不要每帧重新选离散位置造成瞬移。曲线箭头尖端与军队锚点共用弧长采样。行军箭头保持连续，不能用地名文字框遮罩挖断路线；头像布局必须避开整条曲线及其描边。城市符号的端点留白与合围圈文字避让单独处理。乱序同帧哈希检查可复现性，连续帧位置与实际画面另查跳跃、遮挡和字幕安全区。

原生地图数据与动作叠层分别核验。上游部分 CHGIS/Hartwell 衍生边界有非商业限制，不能仅凭仓库的 GPL 标识认定所有地图内容可用于公开视频；技术研发可继续，正式制作按实际采用图层记录许可与史料依据。完整保留原生画法与替换具体数据源可以分别进行。

## 准备可复现底图

优先复用覆盖目标地区且许可明确的本地缓存。新地区按需要取得 DEM、河流、海岸线、城市坐标和历史边界，冻结下载原件、版本、SHA-256、访问日期及署名要求。具体来源和已有实现限制见 [references/data-and-reuse.md](references/data-and-reuse.md)。

现代地形和城市可提供地理参照，但不能证明古城址、古河道或历史国界。没有合适的古国界数据时，用明确标为“示意”的控制范围、核实的地点和独立历史总览；不要替换现代国界的标签冒充古代边界。最终渲染只读本地资产，不依赖在线瓦片。

底图、城市、路线和色块必须用同一投影与画幅变换。保存经纬范围、投影、栅格尺寸和地理坐标到画面坐标的关系。先核对城市与路线终点，再做运镜；裁切、缩放或切竖屏后重新核对。

底图要有定位上下文：按画幅选择少量周边城市、河流或区域名，主地点突出，次地点降低权重。现代省界只能淡线作现代位置参照。按最终构图检查地形采样是否出现明显方块或模糊放大；输出 1920×1080 并不证明地形源具有足够细节。调整范围、瓦片层级和晕渲对比度优先于增加装饰。

当前自动流程使用实测高程晕渲与独立矢量河网：`prepareMotionMap()` 组合 `map-data.mjs` 的地形和 `map-geography.mjs` 的河流、海面与地理名称，交给 `HistoryMapScene` 的 `relief-atlas` 样式。优先读取本地缓存；细高程下载失败就使用完整的已有缓存，并记录实际 provider、原始采样尺寸和放大比例。东部中国优先 HydroRIVERS，区域外按可用 Natural Earth 数据回退；不能声称任意地区都有同等河网密度。明代语境过滤已知现代河道差异，无法复原的古河道留空。数据覆盖、入口与来源限制见 [数据与复用](references/data-and-reuse.md#通用制图实现)。

## 动画与排版

使用 Remotion 帧时钟控制 SVG/画面层：真实底图 → 地理边界与河流 → 半透明势力区域 → 城市和山脉名称 → 行军箭头与部队 → 标题、图例和字幕。

- 路线随行动描出，部队位置沿路线移动，抵达或截断处才出现短促强调；用浅色完整路线提示终点，主线与移动箭头表达当前位置，避免观众先看见一条无起终点的飞线。
- 战事地图按叙事加入武将头像或步兵/骑兵队形及阵营旗号，使用城市投影为锚点；头像旁姓名与阵营可读，必要时用引线避开地名、标题和字幕。行军时沿同一路线与箭头同步移动，抵达后驻留，旗帜可轻微摆动。多个兵形仅为符号，不表示实际人数。
- `hold` 表示驻军，`march` 表示行军，`attack` 表示进攻，`retreat` 表示撤退；这些动作不改变城市归属。只有正文明确占领、归附或收复时使用 `occupy`，在动作结束后改变城市颜色并留下旗帜。王府控制、未克城池、战场附近活动不能画成整城被占领。
- 武将头像由现有图片服务按人物缓存，属于示意立绘；全任务默认最多新增四位，其他人物使用军队符号与姓名。同一人物身份叠层可以跨镜复用，底层视频/场景图片仍遵守全片不重复。头像生成失败不阻断地图，保留军队与姓名，不反复提交同一失败请求。
- 势力消长应让可见的控制边界、区域遮罩或归属发生变化；单纯全片淡入不表示领土推进。临时突出部可用斜纹，稳定控制用实色。
- 包围压缩用由外向内的部署箭头、分段外圈或区域收拢表达，并明确区分“计划部署”和“已发生控制变化”。没有史料时不画成精确历史封锁线。
- 镜头先建立全局，再按叙事聚焦，变化后保留可阅读停顿。相机关键帧围绕目标地点或变化区域移动，地形与城市/路线共用坐标变换；文字、箭头和线宽在屏幕上保持可读，避免运镜后漂移、遮挡或无限放大。
- 城市可按城池、都城、关隘或战场使用不同符号，分类需要本段语境依据。河名绑定实际河段，主支流分级；山脉与地区名保留来源锚点，避让不能把半岛名称移到海面。空间不足时优先省略次要地理名，城市可用引线内移；军队与城市归属仍在真实投影锚点上。
- 短阶段说明只写“围绕瑞金部署 → 活动空间受压”这类动作和结果，不再次排整段旁白。图例直接对应阵营/图形；标题、阶段说明和图例避开完整字幕。
- 来源署名、史实与示意说明放入适合媒介的位置，并在随片报告保留完整来源。地图里保留必要城市、图例与比例关系，不放调试字段。

现有长平片展示了真实地形和示意控制层的结合；它是一个历史案例，不能把固定地名、阶段或故事直接用于别的战役。一般动画细节可参考 [videoeditor 的地图说明](../videoeditor/references/map-animation.md)。

## 检查与交付

先渲染实际旁白对应的 5–12 秒地图镜头，查看建立、变化中、结果停留三个阶段及动作附近的连续帧。明确记录到底哪个对象移动、区域如何改变；只有相机漂移、背景淡入或地点闪光不能证明完成攻守推演。核对地图配准、城名遮挡、旁白触发点、图例与归属；静态截图只证明构图，不证明动画。通过 `ffprobe` 检查实际尺寸、帧率、时长和音轨，记录输出哈希及未完成的听审/视觉审阅。短片通过后复用同一数据与组件接入整片，普通制作不重复增加前置审批。

无法核实地图信息时，记录缺口并自动回退合适素材或独立生成图片，信息动效作为媒体上的解释层；保留完整旁白，不把地图缺口变成人工确认闸门，也不以独立纯色文字卡填补。自动生产使用 `history-motion-maps.ts` 的 `prepareMotionMap()` 和通用 Remotion 地图层；现代地点与示意行动层分开记录依据。完整视频组合由 [remotion-history-factory](../remotion-history-factory/SKILL.md) 处理；已有全画幅视频精修由 [videoeditor](../videoeditor/SKILL.md) 处理。
