# 短地图镜头的叙事与动画

地图镜头先用一句话写清观众应理解的关系、动作或结果。空间部署、战役成败、势力范围消长、行军路线、各方势力兴衰消亡均可成为地图镜头的核心；以已保存旁白为边界，不改正文，不用新增“史实”填充地图。

## 表达任务

| 任务 | 最少地理上下文 | 可见动作 | 结果停留 |
| --- | --- | --- | --- |
| 位置关系 | 主地点、少量周边地点/河流/区域名 | 全局建立后聚焦主地点 | 保留参照物，让观众知道它在哪里 |
| 行军或传递 | 核实的起终点、必要中间节点 | 路线描出，箭头沿路线推进 | 起点、终点与完整路线同时可见 |
| 攻守或归属变化 | 双方图例、相关城/关口与区域 | 阶段切换，区域显隐、边界移动或归属换色 | 新旧状态的差异可读，说明变化发生在哪里 |
| 包围或压缩 | 中心与外围的关系、必要地形参照 | 分方向箭头、分段部署圈或区域收拢 | 保留受压空间与外围部署，不让动画最后全部消失 |
| 战役成败 | 战场、相关军队与关键据点 | 按旁白表现败退、守住、失守或收复；胜负本身不触发整城换旗 | 明确谁胜谁败，以及正文已说明的结果 |
| 势力范围消长 | 有依据的据点归属或控制范围 | 据点依次易手；有核实区域数据时才改变范围 | 可读地保留扩张或收缩后的控制状态 |
| 势力兴衰或消亡 | 本镜涉及的势力、关键据点及阶段 | 按正文依次呈现崛起、衰退或终结的地点与结果，不因抽象兴衰词虚构疆域 | 保留本镜已说明的最终局势；一次战败不表示整个势力消亡 |

这些是表达任务，不是新增的 `presentation.kind`。复用下方已有定位、路线、包围与军队行动字段；缺少可核实地点或无法用现有字段清楚表达时回退素材或图片，不为填充地图编造事实。

“以瑞金为中心，在外围构筑包围圈”适合包围部署示意。可以用围绕核实地点的概念态势层说明中心与外围关系；不能只放一个瑞金点，也不能把任意圆圈写成史料核实的真实封锁线。画面应标“部署示意”，报告说明圈形、箭头与半径是表达方式，不是军队坐标或精确历史边界。

## 可执行字段示例

当前工厂接受的最小 `mapPlan` 例子如下。它只声明叙事关系，坐标、圈形和相机关键帧由地图准备器依据本地地理数据生成：

```json
{
  "title": "计划：围绕瑞金部署",
  "places": ["瑞金"],
  "presentation": {
    "kind": "encirclement",
    "target": "瑞金",
    "label": "计划：外围构筑包围圈",
    "compress": false
  }
}
```

调用时把锁定旁白对应的实际镜头时长传给 `prepareMotionMap()`，不要为了增加动画而改写旁白：

```ts
const map = await prepareMotionMap({
  ...mapPlan,
  duration: 5.1,
  directory: jobDirectory,
});
```

`presentation.kind` 目前只有 `locate`、`route`、`encirclement`。`route` 还必须提供 `routes`；`target` 必须是 `places` 中的地点。`compress: true` 只在旁白明确说收拢、压缩、逼近等动作且镜头至少 8 秒时有意义；5 秒左右的镜头只做“建立 → 部署圈出现 → 结果停留”。包围圈的几何始终是“部署示意”，不能当作已核实的古代边界、封锁线或军队坐标。

### 城市驻军、武将与占领

```json
{
  "title": "盛庸追击 · 收复德州",
  "places": ["济南", "德州"],
  "routes": [{"from": "济南", "to": "德州", "label": "乘胜追击"}],
  "presentation": {"kind": "route", "label": "盛庸追击，收复德州"},
  "forces": [{
    "id": "sheng-recapture", "commander": "盛庸", "faction": "朝廷军",
    "flagText": "明", "color": "#365b7b", "city": "德州", "routeIndex": 0,
    "action": "occupy", "troopKind": "infantry", "start": 2.15, "end": 4.45
  }]
}
```

这是 5.4 秒镜头的例子，`start/end` 是本镜秒数。`city` 必须在 `places` 内，指定路线时必须是该路线终点；同一路线的部队共享起止时间，箭头与部队同步。`march/retreat` 必须引用路线；`attack` 只在包围示意中可以不指定路线，此时部队在既有圈形外围短距推进，不代表精确兵位。无路线的 `hold/occupy` 锚定城市。模型只给符号化决定，头像由后端解析并冻结，不接收模型文件路径。

每镜最多八组标记；短镜头优先一位主将或一个主要军队动作。`occupy` 在 `end` 后换城市颜色并留下旗帜，其他动作都不换归属。驻军和抵达的武将/部队保持到镜尾。跨镜控制延续需要在新镜的计划明确保持已有状态，不能把上一镜控制变化默认为后续任何时代仍然成立。

## 5–12 秒的节奏

5 秒镜头只安排一个主要变化：前约 15% 建立地区和主地点，中间约 60% 展示动作，最后约 25% 停留结果。8–12 秒可加入第二阶段，例如“外围部署 → 向内压缩”；不把所有路线、城市、区域、图例在第一帧一起弹出。

时间以真实旁白为准。地图内阶段可使用归一化进度映射到镜头时长，关键字触发点则按实际时间码设置。结尾保留至少足以看清最后状态的停顿；短镜头宁可少一条箭头，也不要让主要动作在切走前才出现。

相机先给观众参照，再聚焦变化位置。位置镜头也可以有有限运镜与地点强调，但只表示定位，不冒充行军或控制变化。镜头已经只有 5 秒时，通常不需要同时大幅平移和缩放。

## 画面层级

主地点采用更大的字和不同标记；周边地点、河流和现代参考边界退后。地形保留山脊与盆地的明暗关系，降低花纹和颜色噪声，不要将高程晕渲强到盖住路线。没有必要的数据层就省略，不画装饰性假河流、假道路或假国界。

一般限制为一个主标题、一个当前阶段说明、两到三项图例。地点标签随地图坐标移动，但屏幕字号、描边和箭头尺寸要受到约束；屏幕层标题、图例和来源不随地图放大。底部为完整字幕保留空间。

## 交付证据

短片至少保留建立、动作中、最终停留三个时刻及一个动作附近的连续帧。检查内容包括：主地点和参照物是否清晰、路线头是否移动、区域状态是否真的改变、结果是否停留、地图与标记是否共用配准、字幕是否被挡。

“文件存在”“有关键帧”“截图看起来像地图”都不能证明地图推演成功。技术报告和实际回看范围分开写；未连续观看、未听审、未做独立历史审阅的项目仍保持未核验。达到本镜表达目的后结束，不为普通镜头再做全域地图考证。
